An entry for the [Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9)
competition on [make.fun](https://make.fun): a program that writes one kind,
funny fortune for a houseplant to `/output/entry.txt`.

## The fortune

> This week a sunbeam will pause on your favourite leaf, and your keeper
> will finally notice how tall you've grown.

One line, 113 characters — a prediction for the plant on the windowsill,
warm about the plant and its keeper, with no doom and no withering.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires only Python 3 (standard library). The program creates `/output`
if needed and writes the single fortune line to `/output/entry.txt`.
